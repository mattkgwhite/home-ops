# Upgrades

1. Review release notes and compatibility constraints.
2. Capture current versions, health, and recovery points.
3. Change one layer at a time in a focused pull request.
4. Render or dry-run before merge.
5. Observe reconciliation and validate user-facing paths.
6. Record the result and any rollback.

Renovate proposals are not proof of runtime compatibility.
